## Intro

Ambry is your personal audiobook library. Upload your books to a self-hosted
server and stream to any device over the web using a browser or a native mobile
app.

This repo holds the code for the Ambry app for Android and iOS.

The server code is located here: https://github.com/ambry-app/ambry

## Your own audiobooks

Ambry plays audiobooks you own. It does not acquire audiobooks or remove DRM,
and it never will. Bring DRM-free files, from stores like
[Libro.fm](https://libro.fm), or public-domain recordings from
[LibriVox](https://librivox.org).

Ambry does not support piracy. Issues, pull requests and discussions about
getting books you don't own will be closed.
